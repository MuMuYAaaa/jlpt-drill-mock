# 练习与模拟考试参考计分

模拟考试结束、练习结果和历史结果共用此规则。依据使用者提供的 N2 分数计算表，按使用者要求将相同权重应用于 N1–N5。此处显示练习参考分，不代表 JLPT 官方量尺分数，也不作官方合格判定。

## 计算

- 文字词汇（含语法）、阅读、听力三个部分，每项满分 60 分。
- 单项参考分 = 答对题目的加权分之和 ÷ 本次该部分全部题目的加权满分 × 60。
- 各项四舍五入保留 1 位小数，总分是显示的各项分数之和；三个部分齐全时总分为 180 分。
- 正确率 = 答对题数 ÷ 本次该部分题数 × 100%，保留 1 位小数。未作答计零分，纳入分母。
- 分母采用实际题量，不写死截图中的示例合计、年份和题数。截图中的合计若与逐行题数相加不一致，以实际题目逐题加权为准。
- 专项、错题、收藏和自定义练习只对本次选中的题目计分。未涉及的部分显示“— / 60 分”和“未涉及”，不当作零分；总分满分为已涉及部分数 × 60，不推算未练部分。

## 每题分值

| 部分 | 题型 | 分值 |
| --- | --- | ---: |
| 文字词汇（含语法） | 汉字读法、汉字表记、词语构成、前后关系、近义替换 | 1 |
| 文字词汇（含语法） | 用法 | 2 |
| 文字词汇（含语法） | 语法形式、句子组织、文章语法 | 1 |
| 阅读 | 短篇阅读 | 2 |
| 阅读 | 中篇阅读、综合理解 | 3 |
| 阅读 | 长篇阅读（截图外的补充类型，暂定） | 3 |
| 阅读 | 论点理解、信息检索 | 4 |
| 听力 | 课题理解、要点理解、概要理解 | 2 |
| 听力 | 即时应答 | 1 |
| 听力 | 发话表达（截图外的补充类型，暂定） | 1 |
| 听力 | 综合理解 | 3 |

因此正确率与分数占比可能不同。例如听力一题课题理解答对（2 分）、一题即时应答未答（1 分），正确率为 50%，听力参考分为 2 ÷ 3 × 60 = 40.0 分。

## 旧记录与导入题库

旧记录在查看时按保存的题目快照和最终答案重新计算；不修改当时的题目、作答、错题或学习统计，不必重做或重新导入备份。

题目根据题型编号分类，与试卷的计时科目分开。101–106 和 201–203 属于文字词汇（含语法），301–306 属于阅读，401–406 属于听力。导入题库出现未配置权重的题型时，该部分仍显示正确率，分数暂显示“—”；有未归类题目时总分暂不计算，不自动编造分值。
