日语研习室 · Windows 分享版 1.2.2

开始使用
1. 安装版：运行“日语研习室-1.2.2-Windows-x64-安装包.exe”，选择空文件夹并安装。
2. 免安装版：先完整解压 ZIP，再运行文件夹里的“日语研习室.exe”。不要在压缩包内直接运行。
3. 无需安装 Node、配置 MCP 或启动安卓模拟器。适用于 Windows 10/11 64 位系统。
4. 程序优先使用 Edge 的独立窗口；没有 Edge 时使用默认浏览器。

内置内容
N1–N5，共 115 套试卷、11,552 道题；全部 3,396 段听力已内置。
包含专项刷题、错题、收藏、模考、备份、粉紫渐变主题与全屏模考模式。
题库与听力可离线使用；部分题目图片仍需联网加载。
模考全屏被中断时锁住作答并暂停计时和听力，恢复全屏后继续。
页面跳转使用短暂淡出淡入，普通练习与列表分页有方向过渡；模拟考试切题保持即时切换。
加载新页面时保留旧内容，避免空白闪跳；系统开启“减少动态效果”后会自动关闭动画。
Windows 系统快捷键仍由系统控制，不能保证完全阻止切屏。
刷题结果（包括专项、综合、错题和收藏练习）显示正确率、答题数量、用时和逐题回顾，不展示参考分。
模拟考试结果显示参考总分、文字词汇（含语法）/阅读/听力三项分数与正确率。
各项按本次实际题量的加权得分比例换算为60分，完整三项满分180分，未答计零分。
不完整模考只汇总涉及的部分，未涉及的部分显示“未涉及”；历史记录按原来的练习/模考类型展示。
N1、N2、N3分别使用提供的对应规则，N4和N5使用N3规则。
N2中篇阅读按原材料分组，末题3分，其余2分，专项抽题保持原分值。
可在结果页展开“查看题型分值”，完整规则见随附的“计分规则.md”。
参考分不是 JLPT 官方量尺分数，也不用于官方合格判定。

学习记录
分享包不含制作者的学习进度；首次使用为全新记录。
你的记录保存在安装目录的 data 文件夹中，请勿删除或只移动 EXE。
换电脑前可在“题库与备份”中导出学习备份，在新电脑中恢复。
关闭窗口后，学习服务仍在托盘；需要彻底退出时，右键托盘图标选择“退出学习服务”。

卸载与迁移
安装版可从 Windows“应用和功能”卸载，或运行安装目录里的“卸载日语研习室.exe”。
卸载前先退出托盘服务；卸载会保留 data 文件夹，便于保留学习记录。
若要彻底清除，确认不再需要学习记录后，可手动删除剩余安装文件夹。
免安装版可先退出托盘服务、导出备份，再删除整个文件夹。
请在新版本的空文件夹中安装或解压，再用导出/恢复迁移记录。

启动问题
优先双击“日语研习室.exe”；不要同时运行两个文件夹中的不同副本。
如果提示端口占用，请先从托盘退出旧副本，再启动新副本。
可双击“启动诊断.cmd”查看本地服务错误。
音频丢失或损坏时，保持联网并运行“下载听力音频.cmd”补齐。
